# 验收与修订

先检查成品是否可以交付，再判断它像不像参考的设计语言。评分是人工视觉判断，不是自动测量结果。

## 不能靠总分抵消的问题

出现以下情况时将结果标为“待修订”，即使很漂亮也不能作为已完成的商品或活动海报：

- 展示了错误的商品、错误型号、错误包装或未经要求变更的人物身份。
- 有错字、漏字、生成伪字；价格、参数、日期与已确认文案不一致。
- 带入只属于参考图的商标、原人物或原文案。
- 把概念信息、未核实的功效或缺失的优惠条件表现成确定事实。
- 内容因裁切、低对比或遮挡无法完成基本阅读。

用户明确只要草图时，可将未完成部分标成占位；交付时必须说明草图状态。

## 设计评分：五项，每项 0–4 分

| 项目 | 核心问题 |
| --- | --- |
| 注意力顺序 | 视线是否仍由相似的版面机制引导？ |
| 字与空间 | 标题的尺度、节奏、留白和信息层级是否成立？ |
| 主体关系 | 主体的画面重量、视角和叠层是否符合约定？ |
| 色与质感 | 色彩职责、对比和表面处理是否形成同一视觉语言？ |
| 行业适配 | 是否准确表达新主题，并通过专项检查？ |

分值含义：0 为缺失；1 为明显偏离；2 为有相似之处但不稳定；3 为达到任务要求；4 为特征清晰且适配自然。

建议交付线：总分至少 16/20，且前述事实与可读性检查全部通过。注意力顺序、字与空间、主体关系三项均至少 3 分。用户选择了明显不同的设计方向时按新简报评分，不为了追分强行改回参考。

没有查看成图时不给分，只有提示词时只检查约束是否完整。

## 找到一个最值得修的地方

先处理商品、文字与事实，再处理结构，最后处理表面细节。写成明确动作，如“把标题留白恢复到画面上三分之一”“恢复瓶盖轮廓”“在确定排版层替换错误价格”。

局部修订需重申已正确的主体、比例和文字，避免让模型重新解释整张图。两轮仍未通过时保存最佳版本并说明未通过项；继续大幅重做前让用户了解原因。

## 系列检查

对照第一张已经认可的图，检查共同的标题层级、商品尺度、信息模块与色彩职责。每款商品可有自己的轮廓和配料表现，不以复制同一张图替代系列设计。
