# 调用示例与提示词模板

以下标题与副标题是虚构示例文案，不代表真实活动或商品事实。

## 三种调用

**只分析**

```text
用 $poster-style-retail 拆解这张海报，给我可用于新主题的设计记录和调整建议，先不要生图。
```

**制作海报**

```text
用 $poster-style-retail，为一家书店做指定商品会员活动海报。
图 1 控制版式与质感，图 2 是我的目标素材，不要把两张图的品牌混在一起。
主标题：会员好书日
副标题：把喜欢的书带回家
请先检查素材与事实是否足够，然后按我指定的比例出图。
```

**做可复用模板**

```text
用 $poster-style-retail 为这张参考海报建立可替换商品和标题的提示词模板，只返回模板，不出图。
```

## 变量

| 变量 | 用法 |
| --- | --- |
| [目标主题]、[受众与用途] | 本次传播任务 |
| [画布比例]、[输出尺寸] | 用户指定；未指定可沿用参考 |
| [主参考图]、[目标素材] | 分别说明风格职责与保真职责 |
| [识别锚点]、[区域安排] | 从参考中提取，不能只填风格形容词 |
| [主标题]、[副标题]、[其他文字] | 逐字内容；英文标题可选 |
| [商品或主体特征]、[辅助元素] | 本次要呈现的内容 |
| [色彩职责]、[材质与光线] | 记录关系和处理方式 |
| [已确认事实] | [确认的会员价]、[适用书单]、[有效期]、[购买入口]；缺项则做待填稿 |
| [日期]、[地点]、[行动入口] | 不适用或未确认则省略 |

## 一整段模板

```text
制作一张用于[受众与用途]的[目标主题]海报，比例为[画布比例]，尺寸为[输出尺寸]。
[主参考图]仅用于控制设计语言：[识别锚点]。不要沿用图中的原品牌、原文案和原主体。
[目标素材]是本次要呈现的主体，保留[商品或主体特征]；其文字与可辨认结构不要改写。
按[区域安排]组织画面，明确第一眼、第二眼和行动信息的阅读顺序。
主视觉为[主视觉]，辅助元素为[辅助元素]，它们应服务于主题和商品识别。
采用[色彩职责]和[材质与光线]，因目标轮廓或文案字数需要时适配局部布局。
逐字文案为：“[主标题]”“[副标题]”“[其他文字]”。空项直接省略，禁止补充随机文字。
事实信息只使用[已确认事实]。日期、地点与行动入口分别为[日期]、[地点]、[行动入口]，未知则不展示。
密集或必须精确的文字区域留作确定性排版，不生成伪字。排除参考专属元素、错误商品特征和未经确认的商业主张。
```

填好变量、删去空项后再交给图片工具。若采用视觉与文字分层，图像提示词改成“预留指定文字区，不生成任何文字”，准确文案另交排版层。

## 示例的内容选择

- 主视觉：用户提供的主推书籍商品图。
- 辅助元素：克制的商品模块与价签区域。
- 版面和光线必须从实际上传的参考图分析，不由本示例预设。
- 缺少价格、功效、参数、时间或地址时保持缺失，不用示例数字填补。
