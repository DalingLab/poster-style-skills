# 零售专项决策

## 先把活动规则写清楚

用一张简表记录商品、标示价格、实际优惠机制、适用范围、有效时间、购买入口。缺失项标为待确认；做最终海报时省略未知事实，或仅交付明确标注的待填排版稿。

| 机制 | 需要明确的条件 | 容易误导的排法 |
| --- | --- | --- |
| 直接降价 | 商品或规格、成交价、有效期（若有） | 大字价与另一款商品绑定 |
| 满减 | 满额门槛、减额、适用范围 | 把“满 300 减 50”画成“直降 50” |
| 折扣、低至 | 比较口径、适用商品和范围 | 把部分款式低至推广为全场 |
| 会员价、券后价 | 会员或领券条件、是否叠加 | 把条件藏到不可读的小字里 |
| 赠品、组合装 | 购买条件、件数、规格 | 让赠品看起来是无条件免费 |

不擅自补充“最低价”“最后一天”“仅剩 X 件”或划线原价。用户资料内部矛盾时，先定位冲突，不替用户挑一个较吸引人的价格。

## 多商品的信息架构

先选主推商品。其余商品可用统一尺寸的模块、同一基线和稳定价签表达。每个价签必须能对应唯一商品；优惠门槛与主价格同时可读，不用装饰覆盖数字或符号。

跨行业冲突按任务目的处理：强调菜品或化妆品质感时使用对应行业版；当价格规则和多 SKU 组织主导任务时由零售版主导，并使用用户提供的商品事实。不要把食品调成美妆包装或混淆零售与产品功能。

## 购买入口与渠道

只使用已提供的地址、网址、活动页或二维码素材。不生成随机二维码当作有效入口。有明确 URL 且工具支持时可用确定性工具编码并验证；否则预留入口区域，说明等待有效素材。

电商首图、门店张贴和社交平台尺寸会改变阅读距离。按用户渠道尺寸适配，避免宣称未经查证的平台通用尺寸或过期规则。文字拥挤时拆成主海报与规则页，不把所有内容缩到无法阅读。

## 零售专项验收

- 价格、小数点、货币符号与实际商品是否准确对应？
- 折扣、满减、券后和会员条件是否清楚且没有冲突？
- 有效期、适用门店、库存表述是否有已确认资料？
- 多商品有没有错图、错规格或错价？
- 行动入口是否真实可用；占位是否被明确标成待填？
