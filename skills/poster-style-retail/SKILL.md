# 零售海报风格工作台

把参考图转成一组可操作的设计决策，再为用户的新主题重新组织画面。分析结论要落到比例、层级和素材处理，不能停留在“高级”“有氛围”等形容词。

## 判断交付目标

按用户请求决定工作深度，不把每次任务都扩展为完整报告：

- **做海报**：有参考图和新主题时，完成分析、提示词、出图与检查。
- **拆解风格**：只整理设计档案和可迁移规则，不调用生图。
- **做模板**：交付变量和完整提示词，未明确要求出图时不生成。

沿用用户的语言与指定比例。缺少可读的海报参考时，先索取参考图；仅有商品白底图时不能把它当成版式参考。若用户明确要无参考的概念设计，说明改为原创方案，不声称还原了某张参考海报。

## 先给素材分工

把输入分成“控制风格的海报”“需要呈现的目标素材”“仅用于了解事实的资料”。同一张图可以承担多个角色，但必须明确用途。

多张海报先按用户指定的主参考分析。未指定且相互冲突时，询问哪张控制版式；能合理互补时简述分工，例如 A 控制版式、B 控制材质。不混合互斥的字体或构图规则。

目标商品、人物、包装或 UI 与参考海报中的原主体分开处理：前者按用户要求保留，后者应被新内容替代。人物身份只有在用户指定并提供目标素材时才保留。

## 收集够用的信息

先确定活动目标、主推商品和渠道。若需要展示优惠，收集成交价、优惠门槛、适用商品、有效期与叠加规则；信息不全时先输出无价格版本或明确待填的排版稿。

只追问会改变结果的缺口。能从目标素材辨认的特征可作为视觉观察，模糊小字、不可见结构和未给出的商业事实不能靠猜测补全。创意口号可以拟写，事实型卖点不能杜撰；概念活动如有虚构信息，应在交付说明中标明。

## 把风格写成设计档案

阅读 [设计记录卡](references/design-map.md)，记录对结果影响最大的参数。支持结论的内容来自所见图像，建议的制作方式另列，不反推设计师、字体名称或所谓原始提示词。

让消费者能读懂买什么、付多少、满足什么条件、去哪里买。装饰不能遮挡价格小数点、优惠门槛或适用范围；多商品海报先分主次，再排列信息。

做拆解时输出关键记录；直接出图时可在内部完成分析，仅向用户简述关键判断。按所见图像估算百分比，不把估算写成精确测量。

## 安排迁移优先级

把记录整理成三个决策区：

1. **识别锚点**：决定这套风格能否被认出的 3–5 个规则，例如标题占比、主视觉入画方向、版面疏密和色彩对比。
2. **适配空间**：随新标题长度、商品轮廓和渠道比例调整的部分，例如换行、辅助图数量、局部留白。
3. **新内容清单**：本次主题、文字、目标素材与必须清除的旧内容。参考里的商标、人物、产品和文字不得因醒目而被误带入。

若用户指定尺寸与参考不一致，以指定尺寸为准，说明保留了什么关系、调整了哪些区域。商品保真、事实准确和文字可读性优先于机械复刻参考位置。

## 从主题到画面

在相关任务中阅读 [专项决策](references/sector-guide.md)。确定一句核心信息、一个视觉中心、必要的辅助元素和阅读顺序。每个新增元素都要帮助识别商品、说明主题或组织信息；不为填空而塞入装饰。

生成前把文案分成“逐字呈现”“可以拟写”“缺失但不必显示”。有精确中文、多项参数、价格条件或小字时，优先生成预留文字区域的画面，再用可用的排版工具合成确定文本。没有排版能力时减少文案，或提供清楚标注的待排版视觉稿；不能把伪字当成完成稿。

## 写出可执行的提示词

按以下顺序组织，并删除不适用的项：

`用途和尺寸 → 各输入图的职责 → 新主题和目标主体 → 识别锚点 → 区域安排与文字层级 → 材质和光线 → 完整文案 → 保真要求与排除项`

逐字文案用引号包围，不要求模型补充未给出的品牌或标签。把目标素材和风格参考分别说明。若只有一个图片输入通道且会混淆角色，先说明限制并选择最能保住目标商品的路径，不把目标包装作为待替换旧内容。

需要模板时阅读 [调用示例与模板](references/prompt-examples.md)。保留真正可编辑的变量，未知事实标注为可省略；不要强制填入不存在的日期、价格或地点。

## 制作与复核

使用当前环境提供的图片生成能力；提交参考图前按工具要求检查本地素材。仅在明确要求制作或修改图片时调用。无可用生图工具时交付完整提示词与设计档案，并说明尚未生成图片。

成图后阅读 [验收规则](references/review-guide.md)，检查风格锚点、目标素材、文字和行业事实。若不合格，先修影响最大的一个问题，保留其余已正确区域；默认最多两轮针对性修订，仍未通过则说明剩余问题，不声称已完成。服务报错可重试一次，持续失败就交付可复用提示词；不擅自改用需要另付费或提供密钥的服务。

## 交付形式

- **海报**：展示最终图、两三条设计迁移说明，以及实际存在的文件路径或下载链接；文字或素材保真仍有问题时一并指出。只给实际看过的结果下结论。
- **风格档案**：给设计记录、三个迁移决策区和行业适配重点；区分观察与建议。
- **提示词模板**：给变量表、一整段可复制的提示词和必要的填充示例。不要只返回零散关键词。

系列任务先明确共同的识别锚点和每款允许变化的部分，完成第一款后据其检查结果校准后续画面。用户已授权整组制作时无需逐张请求确认。
