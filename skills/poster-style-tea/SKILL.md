# poster-style-tea

目标是做出一眼能认出真实商品、文字可信、风格完整且适合发布的茶饮商业海报。参考图只提供视觉语法；用户的新商品图和品牌资产才是内容真源。

## 用户已确认的默认风格

用户只提供新产品图，或要求“同风格”“按之前的风格”时，默认使用 [暖纸茶饮海报模板](references/warm-paper-preset.md)，无需再次索要参考海报、品名或 slogan。默认画幅 2:3；缺失文案按模板主动拟写。背景主色根据新产品颜色优化，不固定为米棕色。用户提供新参考或明确提出不同风格、名称、文案、画幅时，以新要求为准。

该模板的两份本地图片只作为风格资产，不能当作新商品来源：
- [字体校对参考](assets/warm-paper-typography-reference.png)：控制细笔书写感、字形与小字比例。
- [用户确认成片](assets/warm-paper-approved-poster.png)：控制整体排布、层级、静物陈列和完成度；不继承其产品、名称、配方、杯套、道具的具体纹理或复制痕迹。

生成时读取并查看以上风格资产，与用户当前产品图分清角色。先保留商品，再搭建新场景；尽量一次确定全部文案和字体，避免连续整图重绘使商品、杯套或道具产生重复花纹。

## 选择模式

根据请求选择一种主模式：

1. **直接成片**：用户提供商品图；可选商品名、风格参考、品牌资产和活动信息。缺少产品名、slogan 或小字时，按参考海报的文字空间主动拟写，再生成并验收海报。
2. **风格规范**：用户只想分析参考海报。输出可复用的茶饮海报系统，不生成图片。
3. **系列模板**：用户想长期复用。输出固定项、受控变量、素材槽位和可复制的 brief 模板。
4. **渠道适配**：用户已有海报或已确认主视觉，需要生成不同画幅版本。保持商品与品牌不变，重排信息而不是机械裁切。

如果没有商品图，只能制作明确标注为概念稿的虚拟产品视觉；不得把它描述为真实商品成片。

## 建立输入角色

在分析或生成前，为每份输入标记唯一角色：

- `STYLE_REF`：只控制版式、字体行为、主视觉机制、配色关系和材质。
- `PRODUCT_ASSET`：目标商品保真真源；数量、杯型、包装、标签、分层、装饰和比例不得擅改。
- `BRAND_ASSET`：已授权的 Logo、标准字、品牌色和图形资产。
- `INGREDIENT_REF`：只证明原料外观，不代表可把原料加入杯中或写进文案。
- `COPY_SHEET`：商品名、价格、卖点、活动规则、日期、门店和免责声明的文字真源。

多张图片角色不清时先根据内容推断，并把推断写进工作记录。会改变商品身份或品牌归属的歧义必须向用户确认。

## 收集最小 brief

正式成片至少需要：

- 一张可用的 `PRODUCT_ASSET`；
- 商品名：已提供则逐字保留；未提供则主动拟定创意品名，在交付中注明为拟名；
- 输出渠道或画幅。

建议收集：品牌资产、可见商品特征、冷热状态、已确认配方、产地、目标人群、传播目的、精确文案、价格与活动条件、禁用内容、风格参考。

价格、折扣、日期、地址、配方、产地、认证和健康或营养卖点必须来自用户确认的信息。未知项保持为空，不补写“0 糖”“低卡”“真果肉”“有机”“限定”等营销事实。

复杂 brief 或系列化任务优先使用 `scripts/build_prompt.py` 生成结构化提示词。它接收 JSON、执行事实与素材预检，并可用 `--validate-only` 只检查 brief。

## 提取两个系统

### 目标商品保真表

从 `PRODUCT_ASSET` 记录：数量、轮廓、杯型或包装结构、朝向、标签位置、Logo、主色、透明度、液面、可见分层、冰块、珍珠或果肉、奶盖、酱纹、顶部装饰、吸管或杯盖以及相对比例。

把这些列为 `Must preserve from destination assets`。允许改善清晰度、光线、冷凝水和接触阴影，但不能重新设计商品。

### 参考风格系统

只从 `STYLE_REF` 提取视觉机制。创建：

- `Hard lock`：版式骨架、标题占比、商品尺度、主要重叠、配色关系、主图处理、密度图。
- `Soft lock`：局部装饰、纹理强度、次要模块、光向、标签数量和点缀形状。
- `Must replace from style reference`：参考商品、人物、Logo、品牌文案、专有角色、场景语义和独特插画内容。

保留空间语法，不复刻完整构图。若参考来自竞品，避免同时继承其标志性色彩、字形、布局和包装陈列组合，降低品牌混淆。

## 制定成片方案

先确定商业阅读路径：品牌或系列 → 商品主体 → 商品名 → 核心口味或卖点 → 价格/行动信息。不是每张海报都需要全部层级；没有确认信息时宁可留白。

先建立参考海报的文字槽位表，记录产品名、slogan、英文和辅助小字的位置、可见字高、占宽、行数、字数容量、行距、对齐和留白，再按空间拟写文案。缺少文案时默认主动完成，不用两字品类名替代一整块多字标题。

商品主导海报的中间大标题默认只放完整产品名；即使分成两行，这两行也必须共同组成同一个品名，不能把一行产品名与一行 slogan 混作主标题。slogan 放入独立的辅助文字槽位，保持次一级字号；用户另有明确要求时按用户要求。

标题排法服从用户要求和参考版式：参考为两行、竖排或错落排布时，可以采用对应排法，不再强制单行。优先调整拟写文案的长度，使字高、标题量感和边距接近参考，避免靠缩小字号塞长名字。用户提供的正式品名不得擅自删字或改写；确实无法兼顾完整名称与可读性时才询问短标题。slogan 和小字按各自槽位容量撰写，不复制参考品牌的原话。品牌未提供时留白，不杜撰品牌。

用户提供标题尺寸/边距示意图时，以其可见字高和安全边距为验收基准，不为塞下长名称把标题缩成次要小字。标题可作为前景字形自然遮挡两侧装饰，但不要用矩形底片、色条或模糊块替文字清场；保留文字间隙中的背景连续性，且不得挡住品牌或商品。裕莲茶楼系列的具体比例见该品牌 Skill。

选择生产路径：

- **商品保真优先**：以 `PRODUCT_ASSET` 为编辑或合成基础，让生成模型补背景、灯光和氛围。不要重新生成整个商品。
- **背景优先**：先生成无商品、无文字的场景并预留区域，再合成真实商品图。
- **文字分层**：精确中文、价格、活动条件和免责声明使用 SVG、HTML 或其他确定性排版工具添加。只有很短且可验收的标题才可直接让图像模型渲染。

提示词顺序使用：

`用途与渠道 → 输入角色 → 商品保真 → 风格锁定 → 构图与阅读路径 → 场景/原料 → 材质与光线 → 精确文字 → 禁止项 → 验收条件`

所有精确文案加引号，要求逐字呈现且只出现一次。明确禁止额外文字、伪英文、随机数字、二维码、水印和未确认卖点。

## 生成与修复

直接成片时使用可用的图像生成或编辑能力，并把商品图作为目标内容真源、风格图作为设计系统参考。不要让风格图覆盖商品身份。

生成后按顺序检查：

1. 商品身份与商品保真；
2. 文案、价格和活动条件；
3. 品牌资产准确性；
4. 商业阅读路径和渠道安全区；
5. 风格系统相似度；
6. 饮品物理、食欲感、穿模和随机文字。

一次只修一个主问题，最多自动修复两轮。商品失真、关键文案错误或虚构营销事实出现时，必须返工；不能用较高的风格分抵消。

## 输出契约

### 直接成片

返回成片、所用输入角色、商品保真摘要、风格保留摘要、精确文案核对结果、验收分数和本地保存路径。主动拟写时另附紧凑的槽位文案表，并标明创意品名与 slogan 为本次拟写。

### 风格规范

返回茶饮海报类型、版式/字体/商品/配色/材质规范、Hard lock、Soft lock、Must replace from style reference、推荐商品槽位和保真优先级。不生成图片。

### 系列模板

返回系列不变量、每张允许变化 2–4 项的受控变量、素材命名规则、brief JSON 模板和完整提示词模板。

### 渠道适配

逐个渠道返回成片或布局方案，并说明哪些元素重排、哪些元素保持不变。不得通过拉伸商品或裁掉活动条件来适配。

## 质量底线

- 商品一眼可认，没有换杯、改包装、改标签、增减商品或添加不存在的配料。
- 精确文案逐字正确；未确认的事实不进入画面。
- 商品名完整，标题字高、占宽、行数、排布与参考槽位相符；允许按参考多行或竖排。拟名及 slogan 不冒充官方既有名称或口号。
- 用户给出大标题示意图时，标题量感、左右边距和字形上层遮挡关系必须符合示意；字外出现方形盖片即返工。
- 参考风格被抽象为设计系统，没有残留参考品牌、商品、人物或专有内容。
- 冷热状态、液体分层、配料重力、冷凝水和光影关系合理。
- 主视觉既有风格辨识度，也能在目标渠道完成商品传播任务。
- 未达到商业验收门槛时明确说明缺陷，不把概念稿称为可发布成片。
