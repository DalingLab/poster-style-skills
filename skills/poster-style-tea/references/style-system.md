# 参考风格提取规范

参考图的作用是提供设计系统，不是提供目标商品和品牌内容。

## 先分类

选择一个主机制，必要时加一个辅机制：商品主导、字体主导、编辑网格、拼贴、插画、3D/超现实、电影叙事或极简符号。茶饮海报通常以商品主导为主，但不要预设。

## 提取顺序

1. 传播目的与第一视觉焦点；
2. 画幅、外边距、网格、主要区域、留白和阅读路径；
3. 标题占比、行数、对齐、字重、字宽、字距、行距、裁切与重叠；
4. 商品或主视觉的尺寸、角度、裁切、层级、落地方式；
5. 背景/主体/标题/强调色的面积关系与对比；
6. 边框、色块、标签、线条、图标和装饰密度；
7. 摄影、3D、插画或拼贴处理，以及光线、颗粒和材质；
8. 各区信息密度与节奏。

使用相对尺寸，例如“商品覆盖画布高度约 62%，位于中下区域，标题与杯顶重叠约 6%”。不要猜字体名、摄影师、艺术家、镜头或原始提示词。

## 锁定地图

### Hard lock

列出 5–8 项最高影响规则：画幅、网格、边距节奏、标题脚印、商品占比、主要重叠、配色关系、图像处理和密度图。

### Soft lock

列出 3–6 项可适应规则：装饰数量、次级模块、局部旋转、纹理强度、光向、小标签与点缀形状。

### Must replace from style reference

替换参考商品、人物、Logo、品牌文案、包装、专有角色、场景语义、活动信息和独特插画内容。

### Must preserve from destination assets

单独列出目标商品图、品牌资产和精确文案中必须保留的内容。不得把它们归入 Must replace。

## 风险距离

当参考来自竞品或知名品牌时，保留抽象结构，但主动改变至少两个次级识别维度，例如装饰图形、局部色彩、场景道具、标题细节或材质表现。不能复用竞品 Logo、包装、口号、吉祥物或容易造成来源混淆的完整视觉组合。
