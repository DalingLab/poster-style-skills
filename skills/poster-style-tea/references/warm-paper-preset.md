# 暖纸茶饮海报：用户确认的默认模板

适用于用户只提供一张新饮品图、希望沿用此前风格的任务。提炼自本次确认的细笔字体校正版；它是可换商品与配色的视觉系统，不是固定奶茶、固定米棕色或固定椰子配方。

## 视觉骨架

竖版 2:3，常规输出 1024×1536 或更高的同等比例。整体是纸感背景上的真实商品静物摄影，配纤细中式手写大标题、轻小字与宽留白。阅读顺序为顶部微字 → 完整产品名 → 商品主体 → 右侧与底部短句。

以下位置为目标区间，应按新杯型、奶油顶高度和正式品名长度做小幅适配，不按绝对像素复刻：

| 区域 | 布局与尺度 |
| --- | --- |
| 外边距 | 左右约画布宽 8–10%，整体疏朗 |
| 顶部微字 | 高度约 5–7%；左、中央、右轻量分布，可删减 |
| 产品主标题 | 中上区域，高度约 14–27%；占画布宽约 42–48%，两行优先 |
| 标题单字 | 可见字高约画布宽 7–8%，约 72–82px / 1024px 宽；按字形光学校准 |
| 标题英文注释 | 标题上下边缘，约 12–16px / 1024px 宽，轻衬线字体 |
| 商品 | 中轴略偏下，连顶部装饰约占画布高 36–43%；从约 34–39% 至 72–78% |
| 商品宽度 | 通常占画布宽 28–36%；按真实杯型等比调整，不拉伸 |
| 陈列底座 | 下部约 69–88%，有承托、有接触阴影，不能压过商品 |
| 侧边短句 | 商品右侧约 39–55% 高度，细竖字配一根细线与微小交叉记号 |
| 底部短句 | 约 92–96% 高度，两角各四字，可两行两字；中央没有品牌就留白 |

标题与商品之间必须保留清晰空档，不能为扩大商品挤掉留白。下部静物稍密，上半部保持轻与空。

## 字体锁定

主标题采用纤细、松弛、略古拙的毛笔手写感：细而略颤的线条，轻重不完全均匀，局部枯笔与断墨，字形略有宽窄和高低差。字距自然，不排列成严整方块。用深茶褐或随配色适配的暗色墨，不用纯黑粗字。

避免厚重湿墨、肥大楷书、过宽三角收笔、标准字库般整齐的字面、夸张大字和高密度墨块。校对时比较可见笔画与字形的量感，而不是只看标称字号。细笔不等于把粗字体降低透明度，也不等于整体模糊。

英文为细小轻衬线体，中文说明小字细、窄、清楚。侧边竖字约 15–18px / 1024px 宽，底角约 26–32px；这些是生产建议，缩图后仍应可读。顶部小字约 15–19px，不能膨胀成第二标题。

## 产品名与文案

大标题只放完整产品名，两行合起来仍是同一个名称。缺名称时主动拟写能匹配商品的创意品名，通常 6–8 字，优先 4+3、4+4 或自然语义断行。不要把一行品名和一行 slogan 合成主标题。用户给定品名时保持完整，不机械凑字。

侧边 slogan 通常 6–10 字，底角各四字，顶部中间约 6–10 字。按区域容量写文案，不把所有空位填满。不重复借用当前案例的“琥珀醇香冰椰奶茶”；这只是此前商品名称，不代表新产品也含椰或具有相同风味。

只根据用户确认的信息、品类与可见外观命名；不能凭颜色猜原料、工艺或茶种。不发明价格、品牌、产地或营养卖点。拟名与 slogan 在交付说明中标明为本次创作，画面中不额外加入“概念”标签干扰设计。

## 随商品调色

保持真实商品本色，主要调整背景、墨色与少量器物颜色。由杯中液体、果肉或奶油等主要商品区域取色，不用原图大面积背景色代替商品色。

背景使用商品色的浅色、低饱和版本，并带柔和纸感。它应比商品更轻、更灰，避免同色淹没主体；暗色商品通常配更浅暖灰底。奶油白、杯口高光和深色文字提供明暗层次。背景约占 65–75%，商品约 18–25%，深色文字与道具约 5–10%，不追求精确面积。

| 商品主色 | 可采用的背景方向 | 文字与道具方向 |
| --- | --- | --- |
| 奶茶棕、琥珀 | 燕麦米、淡奶咖、暖纸褐 | 深茶褐、胡桃木 |
| 绿色 | 浅鼠尾草绿、灰豆绿、淡青瓷绿 | 深橄榄褐、奶油陶器 |
| 粉红、莓红 | 淡藕粉、米粉灰 | 深莓褐、米白 |
| 橙黄 | 淡杏、浅麦黄、奶油米 | 深栗褐、暖陶色 |
| 紫色 | 灰芋紫、淡紫米灰 | 深灰紫、米白 |
| 乳白或近黑 | 暖灰米、灰褐或适当加深的浅底 | 按杯缘与液体对比选择深浅 |

以上是色彩映射，不是配方判断。主色保持低饱和，避免荧光色、艳丽大色块或强烈数码渐变。

## 商品、陈列与光线

新产品图是唯一商品真源：保留杯型、包装、Logo、标签、颜色、层次、冰块、奶盖、顶部配料与比例。允许清理背景并匹配环境光，不加不存在的杯套、标签或配料。高保真优先保留商品像素或以商品图为编辑基础。

柔光从左上方进入，阴影向右下延伸；有杯缘细高光、适度液体透光与真实接触阴影。背景像细纹纸，杯体像塑料或玻璃本身；禁止把纸感覆盖到整杯，禁止凭空出现浮雕、涡旋纹、重复花纹或装饰刻纹。

底座通常由温润木器、浅色陶器或石材构成，配少量亚麻；选 2–3 类有用陈设即可。不必每次都是同一碗、同一木墩、同一位置。只有原料已确认时，才可将其作为道具；不因参考有椰子便一直放椰子。

## 固定项、变量与验收

固定项：轻细手写标题、完整品名、上松下密的轴线布局、留白、纸感、真实静物摄影、柔光与小字层级。

受控变量：新商品、产品名与辅助文案、背景色系、少量陈设。画幅默认 2:3，用户指定时重新排版。

优先检查：商品有没有被改造；主标题是否完整品名；字是否仍粗大厚重；标题与小字是否接近指定量感；产品是否从背景分离；文字是否准确；是否出现无依据原料、旧商品或旧品牌。使用完整风格与商业验收表，不因配色变化降低结构要求。

## 单图调用流程

查看新产品图与本技能两份风格资产 → 记录商品保真项 → 拟品名与槽位文案 → 依据商品色建立浅色背景方案 → 以商品图为基础生成或合成 → 核对字体、文案、商品与配色 → 返回海报与原图路径。无需用户重复提供旧参考；仅当重要品牌信息或商品事实确实不清楚且影响成片时再追问。
