# 按参考文字空间拟写文案

用户未提供产品名、slogan 或小字时，默认主动完成这部分创作。保留参考的文字层级与空间容量，替换其语义内容。

## 文字槽位表

生成前为参考图中实际存在的文字区域记录：

| 项目 | 内容 |
| --- | --- |
| 角色 | 产品主标题、slogan、顶部小字、英文注释、侧边竖排、底部短句 |
| 空间 | 相对位置、可见字高、占画布宽高、边距与留白 |
| 排法 | 行数、每行字数、字距、行距、对齐、横竖方向与错落关系 |
| 文案 | 新商品适用的最终文字、依据、用户提供或本次拟写 |

按字形尺寸和占用空间验收，不只数相同字符。中文与英文长度不可机械互换。参考主标题若约七字分两行，新标题应有接近的量感；不能变成同字号的两个字而让标题塌缩，也不能把八字硬挤进一行。

## 创作边界

- 中间大标题默认是完整产品名，多行是同一个品名的排版，不是一行品名加一行 slogan。例如“琥珀醇香／冰奶茶”共同组成拟名“琥珀醇香冰奶茶”；slogan 只进入独立辅助槽位。不要把“加冰慢享”等行动短句塞入产品名标题区。
- 已提供的正式品名和精确文案逐字保留。缺省时可围绕已知品类、可见外观、已确认口味和日常情绪拟创意品名；交付中注明“创意拟名”，不必把标注加在海报中。
- slogan 用简短、有画面感的非事实表达，匹配原槽位的节奏、容量与字号，不复制参考口号。
- 侧边与底部短句可以描写饮用场景或情绪；冷热须有用户或画面依据。原料种类、工艺、产地、认证、营养、功效和促销属于事实，不能用创意授权替代确认。
- 不凭绿色断言抹茶或开心果，不凭棕色断言红茶品种、焦糖或咖啡，不凭白色断言特定乳源。
- 英文应有明确含义，对应已知品类或拟写主题。品牌缺失处可留白或改为非品牌主题文字，不造 Logo 或假英文。
- 背景主色可按商品主色适配，同时保留背景、商品和文字的明暗对比，不改变真实商品颜色。

## 排版与交付

允许按参考多行、竖排和错落排版；用户指定单行时才锁定单行。优先改拟写文案长度，保住参考字高、标题占比和留白。用户提供的正式长名称确实无法完整放入时，再确认短标题。

生成前将文案与布局写入 brief 的 `product_name`、`copy_status`、`title_layout`、`copy_layout` 和 `exact_copy`。脚本负责校验与编排，不代替创作。成片后逐槽核对文字准确性、尺寸层级和参考空间关系，并附简短文案表。
